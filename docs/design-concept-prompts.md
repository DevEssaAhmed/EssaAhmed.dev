# Portfolio concept prompts

Three preview-only boards generated with the built-in image tool. The tool does not expose a model-version selector, so no specific model version is claimed. All article text, artwork, and project examples are illustrative, not verified portfolio evidence. No application code changed.

Each board shows light and dark desktop home, writing archive and article templates, plus light mobile home and dark mobile article. These are style explorations; responsive behavior and accessibility still require implementation and testing.

## Workshop

Use case: ui-mockup. Create a highly polished large high-resolution website design presentation board for Essa Ahmed, Analytics Engineer. This is a preview-only concept, not a finished website. Board must show EIGHT orderly flat front-on UI views in TWO aligned rows: upper row LIGHT THEME desktop homepage, blog archive, article reading page, slim mobile homepage; lower row DARK THEME matching homepage, archive, article, slim mobile article. Label each view clearly. Give the desktop screens enough width and the page content enough scale for strong hierarchy. Same typography and same layouts across light and dark with thoughtfully adjusted colors. All desktop navs say "Essa Ahmed", "Work", "Writing", "About", and a small sun/moon toggle. Use sample copy based on analytics engineering and decision systems; no fabricated client names, achievements, metrics, or testimonials. Article example "What makes a metric useful?" and blog titles are clearly conceptual editorial examples. Blog archive includes search, topic filters, featured entry, article list with reading times. Article template includes a readable central prose column, discreet table of contents, SQL code block and related writing. Mobile has generous tap targets and a real single-column reading composition. Do not use device hardware, perspective mockups, stock landscape photos, glassmorphism, generic analytics dashboards, giant shiny abstract blobs, or repeated SaaS cards. Clean gutter between screens. Include small board footer "Exploratory design · Illustrative content".
Direction 01: THE WORKSHOP. Friendly, inventive, tactile digital workspace of an analytics engineer. Strong humanist sans-serif headlines, mono labels, tiny handwritten notes used sparingly. Light palette soft white, forest green text, restrained tangerine marks and pale yellow annotation paper. Dark palette deep forest charcoal, soft white text, amber marks and muted moss annotation surfaces. Home headline "Making data useful." accompanied by a small personal intro "I'm Essa. I build reliable data systems and write about what I learn." Asymmetrical composition: large headline left, a carefully arranged collage of ORIGINAL illustrative SQL worksheet, annotated data lineage map and tiny chart artifact right. These are project documents laid out on a work surface, not dashboard widgets. Selected work below as large numbered horizontal project records with thumbnail artifact, role and text links; labels "Data foundations" and "Decision systems" without claiming actual project titles. Underlines and corner annotations add personality; generous whitespace. Blog looks like a notebook index with dates in margin and a pinned featured note. Article has warm technical notebook atmosphere and fine margin notes. Dark mode has same warmth and legibility. Highest quality art direction, distinctive personal site, precise buildable UI. Board heading "01 / THE WORKSHOP".

Direction 02: THE JOURNAL. A striking contemporary independent personal publication. In dark mode the editorial art is recolored without turning the entire screen into a flat inversion. Mobile preserves striking masthead, strong content hierarchy and comfortable paragraphs. Direction 03: THE DATA STUDIO. A sophisticated interactive personal portfolio using ONE bespoke 3D installation to communicate analytics engineering. Broad expressive geometric sans-serif headings, sharply typeset small UI, massive negative space, restrained orange accent; quiet and cinematic, designed like a museum of useful systems. Light theme chalk-white, graphite, muted terracotta-orange, architectural soft shadows. Dark theme black graphite, silver-white, ember-orange, moody but readable studio lighting. The HOMEPAGE hero is a striking large physical three-dimensional installation of small matte ceramic blocks flowing through a translucent smoked-glass channel into three neatly aligned stacks, representing "Collect → Model → Decide". It looks like an original handcrafted data machine on a clean studio surface, never a generic blob, orb, globe or neon portal. Headline "From complexity to clarity." with personal intro "Essa Ahmed / Analytics Engineer" and "Explore my work →". An understated three-stage scrubber below suggests users can inspect the process; hero interaction never covers the text. A quiet selected-work rail below offers "Data foundations" and "Decision systems" with process artifact thumbnails, no false result metrics. Header differs from other concepts with a compact typographic EA name mark next to full name. Blog archive inherits typography/material lighting and uses one beautifully cropped 3D still as a featured story thumbnail, followed by a restrained and highly readable article list; filters, search, reading times visible. Article is deliberately calm with generous readable sans body, one simple static technical diagram, anchored contents, SQL code block and related articles. No decorative WebGL in article body. Mobile homepage shows a smaller static version of the machine below headline and CTA. Both themes are carefully independently lit and materially believable. Board heading "03 / THE DATA STUDIO".
